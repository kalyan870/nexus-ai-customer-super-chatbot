# Technology Stack (`TECHSTACK.md`)

| Layer | Technology |
| --- | --- |
| **Frontend** | React 18, Vite 6, Tailwind CSS, Lucide Icons, `@clerk/clerk-react` |
| **Backend** | Node.js, Express.js, Helmet, Zod, `jsonwebtoken`, `@clerk/backend` |
| **Database** | Neon PostgreSQL (`@neondatabase/serverless`) + Local In-Memory/JSON Adapter |
| **Cloud & Edge** | Cloudflare Workers & Turnstile, Vercel Services, Firebase Hosting, GitHub Pages |
| **Testing & CI** | Node.js built-in test runner (`node --test`), GitHub Actions |
